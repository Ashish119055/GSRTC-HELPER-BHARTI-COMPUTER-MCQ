# GSRTC હેલ્પર ભરતી – બેઝિક કોમ્પ્યુટર MCQ

GSRTC હેલ્પર પરીક્ષા માટે બેઝિક કોમ્પ્યુટર જ્ઞાનના **500 ગુજરાતી MCQ**, દરેક પ્રશ્ન સાચા જવાબ અને સમજૂતી સાથે.

🔗 લાઇવ પેજ: https://ashish119055.github.io/GSRTC-HELPER-BHARTI-COMPUTER-MCQ/

**વિષયો:** કોમ્પ્યુટર પરિચય અને ઇતિહાસ · હાર્ડવેર અને ઇનપુટ-આઉટપુટ · મેમરી અને સ્ટોરેજ · સોફ્ટવેર અને Windows · MS Word · MS Excel · PowerPoint અને MS Office · ઇન્ટરનેટ, ઇમેઇલ અને નેટવર્ક · સાયબર સુરક્ષા અને ડિજિટલ ઇન્ડિયા · શોર્ટકટ કી · ફુલ ફોર્મ અને નંબર સિસ્ટમ

**મોડ:** 🎯 ક્વિઝ · ⚡ 60 સેકન્ડ સ્પીડ રાઉન્ડ · ⏱ મોક ટેસ્ટ (25 પ્રશ્ન / 20 મિનિટ) · 📚 બધા પ્રશ્નો (શોધ અને ⭐ સેવ) · ❌ મારી ભૂલો

> આ સ્વતંત્ર પ્રેક્ટિસ પેજ છે, GSRTC નું સત્તાવાર પેજ નથી.
